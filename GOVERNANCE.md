# Project Governance

## Maintainer
Riders Track Map is maintained by Oresti Ev.
The maintainer has final authority over:
- Accepting or rejecting contributions
- The direction and roadmap of the project
- Any decision to commercialize the project
- Convening the Contributor Pool when relevant

## Contributor Pool Voting
When a vote is called among the Contributor Pool:
- Each contributor with at least one accepted PR gets one vote
- Votes are conducted transparently via a GitHub Discussion or Issue
- Decisions require a simple majority
- The maintainer participates in the vote as a contributor

## Amendments
These governance terms may be updated by the maintainer at any time.
Contributors will be notified via a pinned issue.
