# Contributing to Riders Track Map

## How to Contribute
- Fork the repository
- Make your changes on a branch
- Submit a pull request to the main repository
- Only contributions merged by the maintainer become official

## Contributor Pool & Profit Sharing

Riders Track Map operates on a good-faith stakeholder model.

**Who is in the pool:**
Every contributor who has had at least one pull request accepted and
merged into the main repository is considered a member of the
Contributor Pool.

**If the project is ever commercialized:**
Should the maintainer (Oresti Ev) decide to commercialize Riders Track
Map in any form — paid app, subscription, licensing, or otherwise —
the Contributor Pool will be convened. Members will vote collectively
to decide how a portion of the revenue or proceeds is distributed
among contributors.

The maintainer retains final decision-making authority over whether
and how to commercialize. The profit-sharing model is a good-faith
commitment, not a legally binding contract. Participation in the
contributor pool does not constitute employment, partnership, or
equity ownership.

**What counts as a contribution:**
- Accepted code changes (merged pull requests)
- Significant accepted documentation or design contributions
  at the maintainer's discretion

## Important
By submitting a pull request, you confirm that:
- You wrote the code yourself or have the right to submit it
- You agree to the LICENSE terms of this project
- You grant the maintainer the rights described in the LICENSE
- You understand the good-faith nature of the profit-sharing model
